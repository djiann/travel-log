Day 1｜品川・大井町（新文化地標與夜間水族館）

🗺️ 行程總覽與備案

主線行程： MoN Takanawa 博物館 → マクセル Aqua Park 品川 → 大井町 TRACKS。
B 計畫（博物館休館）： 改為早上先逛品川 ecute 或高輪周邊，下午再進水族館。

🕒 每日詳細行程與交通
  • 早餐 08:00–09:00 品川 / 高輪周邊早餐
    今天主軸集中在高輪、品川、大井町，全部都在 JR 京濱東北線/山手線南側，動線短、第一天不會太累。早餐建議直接在品川站或高輪 Gateway 附近吃，避免一早跨區。
  • 上午 09:00–09:30 前往高輪 Gateway → 進入 TAKANAWA GATEWAY CITY📍地圖
    【串連理由】先去最北的高輪，再一路往南到品川、大井町，避免午後回頭。建議 09:20 前抵達高輪 Gateway，先找好出口、廁所與置物櫃。
  • 上午 09:30–12:15 MoN Takanawa 博物館📍地圖
    【停留】約 2.5 小時。先看當期主展，再保留 20–30 分鐘逛建築公共空間與商店。這裡是 2026 新地標，重點不是只打卡，而是把展覽、建築、Takanawa Gateway City 一起看。
  • 午餐 12:15–13:30 高輪 / 品川午餐
    【轉場】從高輪 Gateway 搭 JR 到品川約 2 分鐘，或沿新開發區慢慢步行到品川約 15–20 分。午餐放品川最順，吃完直接接 Aqua Park。
  • 下午 13:30–14:00 品川站高輪口 → Aqua Park 入場準備
    【重點】先在品川站補水、上洗手間，水族館內外人多時動線較擠。若有行李或購物袋，先用站內置物櫃。
  • 下午 14:00–17:15 マクセル Aqua Park 品川📍地圖
    【停留】約 3 小時。建議路線：入口水母區 → 小型展缸 → 海底隧道 → 企鵝/海豹區 → 海豚秀場。海豚秀開始前 20–30 分鐘進場找位置，傍晚燈光效果更漂亮。
  • 傍晚 17:15–17:45 品川 → 大井町
    【交通】JR 京濱東北線 1 站，車程約 3 分鐘；含走路等車抓 20–30 分鐘。這段是全日最短轉場，所以適合第一天安排。
  • 晚上 17:45–20:30 大井町 TRACKS（OIMACHI TRACKS）📍地圖
    【停留】約 2–3 小時。先走 2–4F 商業區，確認想吃的餐廳排隊狀況，再決定晚餐。吃完可逛生活雜貨、咖啡甜點或屋外公共空間。若當天體力不足，20:00 前回飯店整理行李。

Day 2｜兩國・晴空塔（下町文化與天空水族館）

🗺️ 行程總覽與備案

主線行程： 江戶東京博物館 → 東京晴空塔/Solamachi → すみだ水族館。
B 計畫（對歷史沒興趣）： 將上午改為淺草寺與雷門，下午再前往晴空塔。

🕒 每日詳細行程與交通
  • 早餐 08:00–09:00 兩國站周邊早餐
    今天主軸在東京東側：兩國 → 錦糸町/押上 → 晴空塔。早餐放兩國，是為了 09:30 準時進江戶東京博物館，避開上午團客人潮。
  • 上午 09:00–09:30 抵達兩國站 → 江戶東京博物館外觀拍照
    【交通】JR 總武線「兩國站」西口步行約 3 分。建議先在兩國國技館外側與博物館建築拍照，再進館。
  • 上午 09:30–12:20 江戶東京博物館📍地圖
    【停留】約 2.5–3 小時。建議路線：常設展入口 → 日本橋模型 → 江戶街區模型 → 明治/昭和東京 → 商店/紀念品。若帶小孩，模型區與互動展示優先。
  • 午餐 12:20–13:30 兩國午餐：相撲火鍋 / 炸豬排 / 壽司
    【安排理由】兩國午餐選擇比押上更有地方特色，吃完再移動去晴空塔。若午餐排隊超過 30 分鐘，直接改江戶NOREN 或車站附近定食，避免壓縮下午。
  • 下午 13:30–14:00 兩國 → 押上 / 晴空塔
    【交通】建議 JR 兩國 → 錦糸町，轉半藏門線到押上；全程約 20–30 分。若不想轉車，可搭計程車約 10–15 分，適合多人或下雨。
  • 下午 14:00–15:30 Solamachi 低樓層購物與休息📍地圖
    【停留】約 1.5 小時。先逛 2–4F 伴手禮、角色商品、甜點，順便找椅子休息。這段安排在登塔前，是為了等下午光線變柔和。
  • 下午 15:30–16:30 晴空塔 8F 千葉工大展示 + 9F 郵政博物館
    【停留】約 60 分。8F 千葉工大展示免費，適合看機器人/宇宙科技；9F 郵政博物館小而精緻，當作室內冷氣休息點。
  • 傍晚 16:30–17:30 東京晴空塔展望台📍地圖
    【停留】約 60–75 分。若天氣好，這個時段可以看到白天到夕色轉換；若雲層太厚，直接把登塔改成 Solamachi 深逛。
  • 晚上 17:45–19:30 すみだ水族館（墨田水族館）📍地圖
    【停留】約 1.5–2 小時。建議路線：水母/藝術缸 → 企鵝池 → 金魚區 → 紀念品店。傍晚夜間燈光比白天有氣氛，跟晴空塔夜景順路。
  • 晚餐 19:30–21:00 Solamachi 晚餐
    【安排理由】水族館與餐廳同棟，吃完可直接搭押上站回飯店，不需要再跨區。若壽司/燒肉排太久，直接改美食街。
